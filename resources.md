# Resources

A short list. Everything here is free unless marked.

## Read first

- [NIST SP 800-82 Rev. 3](https://csrc.nist.gov/pubs/sp/800/82/r3/final): the reference guide to OT security
- [CISA Cross-Sector Cybersecurity Performance Goals](https://www.cisa.gov/cross-sector-cybersecurity-performance-goals): prioritized baseline
- [SANS Five ICS Cybersecurity Critical Controls](https://www.sans.org/white-papers/five-ics-cybersecurity-critical-controls/): where to spend first
- [MITRE ATT&CK for ICS](https://attack.mitre.org/matrices/ics/): adversary techniques
- [Top 20 Secure PLC Coding Practices](https://plc-security.com/): for the people who write the logic

## Stay current

- [CISA ICS advisories](https://www.cisa.gov/news-events/cybersecurity-advisories): vendor vulnerabilities, published several times a week
- [CISA Known Exploited Vulnerabilities catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog): what's being used in real attacks

## Training

- [CISA ICS training](https://www.cisa.gov/resources-tools/programs/industrial-control-systems-and-operational-technology-cybersecurity-training): free virtual and in-person courses

## Tools for visibility (passive)

- [Wireshark](https://www.wireshark.org/): dissectors for most industrial protocols
- [Zeek ICSNPP parsers](https://github.com/cisagov/icsnpp): industrial protocol logging for Zeek, from CISA
- [Malcolm](https://github.com/cisagov/Malcolm): network traffic analysis suite with OT protocol support
- [CSET](https://github.com/cisagov/cset): CISA's self-assessment tool for standards such as the CPGs and 800-82

## Build a lab

- [OpenPLC](https://github.com/thiagoralves/OpenPLC_v3): open-source PLC runtime
- [opcua-asyncio](https://github.com/FreeOpcUa/opcua-asyncio): OPC UA client and server in Python
- [pymodbus](https://github.com/pymodbus-dev/pymodbus): Modbus client, server and simulator in Python
- [GRFICSv2](https://github.com/Fortiphyd/GRFICSv2): simulated chemical plant with a 3D view, for attack and defense practice
- [Conpot](https://github.com/mushorg/conpot): ICS honeypot

## Books (paid)

- Eric Knapp and Joel Langill, *Industrial Network Security*
- Kim Zetter, *Countdown to Zero Day* (Stuxnet)
- Andy Greenberg, *Sandworm* (the Ukraine attacks)
